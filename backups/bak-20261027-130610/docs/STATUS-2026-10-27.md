### 2.2 状态进度条（`core\ui.py:53`）

**改前**

```python
# 每格：█答对 ▓答错 ▒跳过 ·未答 ◆当前题
if start <= idx < start + step:
    cells.append(cyan("◆"))      # 当前题把状态盖掉

```

**改后**

```python
def status_bar(status, idx, limit=60):
    """每格：█答对 ▓答错 ·未答（跳过同未答）；当前题用 [ ] 框住，保留状态色。"""
    for start in range(0, n, step):
        chunk = status[start:start + step]
        if "bad" in chunk:      cell = red("▓")
        elif "ok" in chunk:     cell = green("█")
        else:                   cell = dim("·")
        if start <= idx < start + step:
            cell = "[" + cell + "]"
```

| 状态 | 改前 | 改后 |
|---|---|---|
| 答对 | `█` 绿色 | `█` 绿色 |
| 答错 | `▓` 红色 | `▓` 红色 |
| 跳过 | `▒` 黄色 | `·` 暗色（同未答） |
| 未答 | `·` 暗色 | `·` 暗色 |
| 当前题 | `◆`（丢状态） | `[█]`/`[▓]`/`[·]`（保状态） |

合并规则：超过 60 题按段折叠，段内 **有错即红 > 有对即绿 > 全未答**。

### 2.7 备份清理（`tools\prune_backups.py`）

**改前**：`shutil.rmtree` 直接删，不可恢复。

**改后**

```python
def recycle(path):
    """SHFileOperationW + FOF_ALLOWUNDO → Windows 回收站"""
    op.wFunc = 3
    op.pFrom = str(path.resolve()) + "\0"
    op.fFlags = FOF_ALLOWUNDO | FOF_NOCONFIRMATION | FOF_SILENT | FOF_NOERRORUI

def dispose(path, big_mb=200, purge=False):
    if path.is_file() and size > big_mb*1024*1024: unlink()  # 大文件直删
    if purge: shutil.rmtree / unlink                        # 显式硬删
    if recycle(path): return "已送回收站"
```

| 参数 | 行为 |
|---|---|
| 默认 | 送回收站，可还原 |
| `--big-mb 200` | 超过 200 MB 的文件直接删 |
| `--purge` | 永久删除 |
| `--keep N` | 保留最近 N 份（默认 3） |

## 3. 当前交互契约（按键与语义）

| 按键 | 作用 | 备注 |
|---|---|---|
| `A`–`H` / `1`–`8` | 选选项 | 单选直接替换；多选再按取消 |

| `F2` | 收藏切换 | 可反复按 |

| `/` + 字母 | 命令：`f` 收藏 `m` 标记 `b` 答题卡 `a` 答案 `e` 编辑 `s` 跳过 `q` 退出 | 两键命令 |
| `#12` | 跳到第 12 题 | |
| `[` / `]` | 上一题 / 下一题 | |
| `?` | 答题卡 | |

数据口径：

| 字段 | 含义 |
|---|---|
| `wrong_counts` | 答错累计次数（同轮重复提交不累加） |
| `right_counts` | 错题库中答对次数，`>=2` → 已掌握，否则 复习中 |
| `wrong_status` | `未掌握` / `复习中` / `已掌握` |
| `wrong_last` | 最近答错时间戳（排序用） |

| # | 现象 | 根因 | 修法 |

## 9. 已知取舍

1. **重复提交只防同轮**：跨轮再答同一题仍累计，符合“多练几遍”的直觉。
2. **跳过不单独显示**：与未答合并，但在结算页仍分列「跳过 N / 未答 M」。
3. **进度条折叠**：题量 > 60 时按段聚合，细节以答题卡为准。
4. **考试中禁用看答案**：`;` 与 `/A` 都被拦截，保持考试语义。
