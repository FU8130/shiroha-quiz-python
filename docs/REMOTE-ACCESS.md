# 远程访问：用手机或另一台电脑打开题库

这份文档讲怎么**不坐在电脑前**时，用手机或别的电脑打开 quiz_py 的网页界面。

程序只有两个界面：命令行（TUI）和内置的本地网页（Web GUI）。所谓「远程访问」，就是把本地网页借一条路给别的设备看，程序没有远端服务器，也不需要联网账号。

先记住三件事：

- 网页服务和数据**都在你自己的电脑上**。Tailscale、Cloudflare 只是把连接转过来，没有「云端题库」这种东西。
- 数据始终是项目目录里的普通文件：`quiz_parser.data\state.json`、`quiz_parser.data\history.json`、`banks\*.csv`、`backups\`、`cloud.json`。网页端读写的也是这一份。
- 程序是纯标准库实现，**没有登录系统，也没有 HTTPS**。谁能连上端口，谁就能看和改你的题库与进度。口令（`--token`）是唯一的门锁，而且**可选、默认不带**（这个参数正在加入，见第 8 节）。

## 1. 先选方式

| 你的情况 | 用哪种 | 看哪节 |
| --- | --- | --- |
| 手机和电脑连同一个 WiFi | 局域网直连 | 第 2 节 |
| 人在外面（流量 / 另一个网络），长期用 | Tailscale | 第 3 节 |
| 临时给外地设备看几分钟，或没有公网 IP 又不想装软件 | Cloudflare Tunnel | 第 4 节 |
| 前三种都不行，且确认有公网 IPv4 | 端口转发 + DDNS | 第 5 节 |

**推荐顺序**（从省事、安全到麻烦、危险）：

| 顺序 | 方式 | 一句话理由 |
| --- | --- | --- |
| 1 | 局域网 | 不用装任何东西，但只能在同一 WiFi 下用 |
| 2 | Tailscale | 不用开路由器端口，流量加密，个人免费额度够用 |
| 3 | Cloudflare Tunnel | 临时地址一条命令就有，但等于把网页挂到公网 |
| 4 | 端口转发 + DDNS | 要求公网 IP、要改路由器、被扫描风险最高，非必要不用 |

如果你不确定选哪个：**在家里用第 2 节；出门在外用第 3 节；第 4、5 节先别碰。**

## 2. 局域网（同一 WiFi）

### 2.1 查电脑的局域网 IP

1. 电脑上按 `Win + R`，输入 `cmd`，回车。
2. 输入 `ipconfig`，回车。
3. 找到你正在用的那块网卡（「无线局域网适配器 WLAN」或「以太网」），看「IPv4 地址」那一行，形如 `192.168.1.23`。

补充：

- 家用网段通常是 `192.168.x.x`、`10.x.x.x`、`172.16~31.x.x`。
- **不要用 `127.0.0.1`**：那是「本机自己」的地址，手机访问不到。
- 电脑换了网络、路由器重启后 IP 可能变，重新查一次。

### 2.2 启动网页服务

命令要在项目目录执行，或直接用启动脚本（脚本会自动切到项目目录）：

```
cd /d F:\workspace\quiz_py
python quiz.py --web --port 8799
```

当前版本等价于只监听 `127.0.0.1`，控制台会打印 `🌐 GUI 已启动：http://127.0.0.1:8799/`。

要让手机能连，服务必须监听所有网卡。如果你的版本已经支持 `--lan`（这是**正在加入**的功能，尚未合入主线），就在同一条命令里加上它：`python quiz.py --web --lan --port 8799`。开启后控制台会额外打印一个形如 `http://192.168.1.23:8799/` 的局域网地址，直接照着输即可。

几个注意点：

- **一定要写 `--port 8799`**。不写 `--port` 时程序会随机选一个端口（0 表示由系统分配），每次启动都变，远程访问没法记。
- 不想自动弹出浏览器，可加 `--no-browser`（这个参数当前版本已支持）。
- 也可以用 `Start-Quiz-GUI.bat` 启动，它会把你给的参数原样传给 `quiz.py`，例如 `Start-Quiz-GUI.bat --port 8799`。
- 新开的命令行窗口别关，关掉就等于关掉服务。退出按 `Ctrl + C`。

### 2.3 手机打开

1. 手机连**同一个 WiFi**（不是流量，也不是访客网络）。
2. 浏览器地址栏输入 `http://192.168.1.23:8799/`，把 IP 换成 2.1 查到的那个。
3. 注意是 `http://`，不是 `https://`；也不要在地址里带 `127.0.0.1`。

### 2.4 Windows 防火墙弹窗

第一次有别的设备来连时，Windows 通常会弹「是否允许 Python 访问网络」：

- 勾选「**专用网络**」（家里的 WiFi 一般属于专用网络）。「公用网络」在咖啡馆、宿舍、学校等环境慎勾。
- 点「允许访问」。

如果当时点了「取消」，之后不会再弹，手动补：

- 简单路径：「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」，找到 Python 并勾上专用网络。
- 彻底一点：「高级安全 Windows Defender 防火墙 → 入站规则 → 新建规则 → 端口 → TCP → 特定本地端口 `8799` → 允许连接 → 只勾专用网络」。
- 规则绑的是 `python.exe` 的具体路径，重装或升级 Python 后可能要重新允许一次。

### 2.5 手机打不开？按这个顺序排查

| 现象 | 多半是 | 怎么办 |
| --- | --- | --- |
| 一直转圈，最后超时 | 防火墙拦了入站 | 按 2.4 放行 |
| 电脑本机能打开，手机不行 | 地址写成了 `127.0.0.1` | 换成电脑的 `192.168.x.x` |
| 能连上但页面打不开 | 端口不对（没固定 `--port`） | 看控制台打印的实际地址 |
| 昨天能用，今天不能 | 电脑 IP 变了 | 重新 `ipconfig`；在路由器里给电脑绑定静态 IP |
| 手机连的是访客 WiFi / 酒店 / 学校网络 | AP 隔离（客户端隔离），设备之间互相看不见 | 换到普通家用 WiFi，或改用第 3 节 Tailscale |
| 手机没连 WiFi | 不在同一网络 | 连上同一个 WiFi |
| 公司/学校电脑 | 安全软件拦截入站 | 换设备，或走第 3、4 节的隧道 |

### 2.6 验证成功

- 手机浏览器能看到**题库列表**（不是空白页，也不是浏览器报错）。
- 能进入练习，**做完一道题并提交**，看到判分结果。
- 手机上刷新页面，**进度还在**；回到电脑看 `quiz_parser.data\state.json` 的修改时间也变新了——说明两边读写的是同一份数据。

## 3. Tailscale（不在同一网络时的首选）

### 3.1 它是什么

两台设备都登录**同一个 Tailscale 账号**后，Tailscale 各给它们一个 `100.x.y.z` 开头的私有地址，组成一个只有你自己能进的虚拟局域网（tailnet）。之后不管人在哪里，访问方式都和同一 WiFi 下一样。

好处：

- 不需要在路由器上开端口，也不要求家里有公网 IP；
- 流量走 WireGuard 加密隧道，链路上看不到明文；
- 免费额度对个人自用（几台设备）足够，具体额度以官网为准。

### 3.2 步骤

1. 电脑：从 tailscale.com 下载 Windows 版安装，登录账号（Google / Microsoft / GitHub 邮箱都行）。
2. 手机：应用商店安装 Tailscale，**登录同一个账号**。
3. 电脑托盘图标里能看到本机地址；命令行也可以执行 `tailscale ip -4` 查看 `100.x.y.z`。
4. 让网页服务跑起来：`python quiz.py --web --port 8799`。
5. 手机浏览器打开 `http://100.x.y.z:8799/`。

第 4、5 步有个前提：手机要**直连 8799 端口**，服务就必须监听 `0.0.0.0`（即需要 `--lan`）。如果你的版本还没有 `--lan`，用下面的替代方案，不要为了这个去改代码。

### 3.3 没有 --lan 时的两个替代

- **`tailscale serve`**：在电脑上执行 `tailscale serve --bg 8799`，把本机的 `127.0.0.1:8799` 发布到 tailnet 内。手机打开 `https://<电脑的 tailnet 名称>` 即可，名称形如 `pc-name.tailXXXX.ts.net`，用 `tailscale status` 能看到。好处是自动带 HTTPS；限制是只有登录了同一 tailnet 的设备能访问，而且 `serve` 的语法在不同版本略有差别，先执行 `tailscale serve --help` 确认当前写法。
- **SSH 端口转发**：电脑启用 Windows 的 OpenSSH 服务器，在另一台电脑上执行 `ssh -L 8799:127.0.0.1:8799 你的用户名@100.x.y.z`，然后在**那台电脑**的浏览器打开 `http://127.0.0.1:8799/`。限制：需要电脑一直开着 SSH 服务、需要知道账号密码，手机上配 SSH 客户端比较麻烦，只适合临时用。

### 3.4 验证成功

- 手机关掉 WiFi、只用流量，仍然能打开地址 → 说明走的是 Tailscale 隧道，不是局域网。
- 电脑上 `tailscale status` 能看到手机设备在线。
- 手机上做一道题，电脑上刷新页面能看到同样的进度（或反过来）。

## 4. Cloudflare Tunnel（临时分享 / 没有公网 IP）

### 4.1 原理一句话

电脑上跑一个 `cloudflared` 小程序，它主动向 Cloudflare 建立一条**出站**连接，把外面的请求转回你电脑的 8799 端口。因为连接是从内往外发起的，所以不用开路由器端口，也不用有公网 IP。

### 4.2 临时地址（最快，适合几分钟的临时访问）

1. 从 Cloudflare 官网下载 Windows 版 `cloudflared`（单个 exe）。
2. 保持网页服务在跑：`python quiz.py --web --port 8799`（本机监听 `127.0.0.1` 就够）。
3. 另开一个命令行窗口执行：

```
cloudflared tunnel --url http://127.0.0.1:8799
```

4. 等十几秒，窗口里会打印一个形如 `https://随机单词.trycloudflare.com` 的地址。手机或外地电脑用浏览器打开它即可。

注意：

- 这个地址**每次启动都会变**，关掉窗口就失效；适合临时看几分钟，不适合长期挂着当入口。
- 临时地址**不需要 Cloudflare 账号**，也就**没有任何访问控制**：任何人拿到这个地址都能打开你的题库。
- 地址可能被扫描器扫到，务必配合口令（第 6 节）使用，用完马上关。

### 4.3 固定域名（长期用更稳）

需要有自己的域名，并把域名托管到 Cloudflare（免费套餐即可，域名本身要花钱买）：

1. `cloudflared tunnel login`：浏览器登录 Cloudflare 并授权。
2. `cloudflared tunnel create quiz`：创建隧道，记下输出的隧道 ID。
3. 在 `%USERPROFILE%\.cloudflared\` 下写 `config.yml`，把 `quiz.你的域名` 指向 `http://127.0.0.1:8799`（具体字段名以 Cloudflare 官方文档为准）。
4. `cloudflared tunnel route dns quiz quiz.你的域名`：自动写入一条 CNAME。
5. `cloudflared tunnel run quiz` 启动；想开机自启可执行 `cloudflared service install`。

### 4.4 风险提醒

- 这一步等于**把你家电脑上的网页放到公网**。没有口令时，知道地址的人能看题库、改进度、翻历史记录。
- Cloudflare 会终止 TLS：你到 Cloudflare 之间是加密的，Cloudflare 到你电脑之间是隧道；但**网页本身没有登录页**，口令是唯一防线。
- 家用宽带的上传带宽有限，加载题库或图片时可能明显变慢。
- 只是自己用的话，第 3 节 Tailscale 更合适；非要公网入口，就把口令设长一点，并只在需要时开。

### 4.5 验证成功

- 手机**用流量**（不用 WiFi）打开隧道地址，能看到题库列表。
- 关掉 `cloudflared` 窗口后再刷新该地址，立刻报错（常见 502 / 1033），说明入口已失效。
- 若开了口令：不带口令时打不开，或只看到要求输入口令的提示。

## 5. 端口转发 + DDNS（最后手段）

只有前面几种都不合适时才考虑。它要求最多、风险最高。

### 5.1 先确认有没有公网 IPv4

1. 在浏览器打开 `ip.sb` 或 `ifconfig.me`，记下显示的公网 IP。
2. 登录光猫 / 路由器管理页，看「WAN 口状态」里的 IP。
3. 两者**一致** → 有公网 IPv4，可以继续。
4. 不一致，或 WAN IP 落在 `100.64.x.x`~`100.127.x.x`、`10.x.x.x` 这类地址 → 运营商大内网（CGNAT），端口转发**通常不通**。可以打客服申请公网 IP（不一定给），否则改用第 3、4 节。

### 5.2 路由器上做端口映射

- 光猫先改桥接、由路由器拨号（或直接在光猫里做映射），否则两层 NAT 要映射两次。
- 找「虚拟服务器 / 端口映射 / NAT」这类菜单：外部端口填 `8799`（也可以换成不常见的外部端口，比如 `18799`，减少被扫描）→ 内部 IP 填电脑的 `192.168.x.x` → 内部端口 `8799` → 协议选 TCP → 保存。
- 顺手在路由器里给电脑绑定静态 IP，否则电脑 IP 一变，映射就失效。
- **不要用 DMZ**：DMZ 是把整台电脑暴露出去，比只开一个端口危险得多。

### 5.3 动态 IP 需要 DDNS

家庭宽带的公网 IP 通常几天变一次。用 DDNS（花生壳、No-IP、DuckDNS、Cloudflare DNS 等）把一个域名指向你的动态 IP；很多路由器内置 DDNS 客户端，填上账号即可。之后用 `http://你的域名:8799/` 访问，IP 变了会自动更新。

### 5.4 加固（不能省）

- **必须加口令**：启动时带 `--token 一长串随机字符`（`--token` 是正在加入的功能，若你的版本还不支持，就**不要**做公网映射）。口令不要用 `123456`、生日、姓名拼音。
- 尽量只允许特定来源 IP：Windows 防火墙「高级设置 → 入站规则 → 属性 → 作用域 → 远程 IP 地址」里填白名单。家用路由器大多不支持按来源 IP 限制，需要软路由或企业级设备。
- 公网上的 8799 端口会在几小时内被自动扫描器扫到。HTTP 是明文传输，口令在链路上可能被看到——所以**能只走 Tailscale 就只走 Tailscale**；公网入口用完立刻删掉映射。

### 5.5 验证成功

- 手机关 WiFi、只用流量，打开 `http://公网IP:8799/`（或你的 DDNS 域名）能进题库。
- 外部网络 `ping 你的域名`，解析到的 IP 与当前公网 IP 一致 → DDNS 生效。
- 在路由器里关掉映射规则后，外网立刻打不开 → 确认走的确实是这条映射，不是别的路径。

## 6. 安全清单

| 项目 | 该怎么做 | 为什么 |
| --- | --- | --- |
| 不用就关 | 用完 `Ctrl + C` 结束服务或直接关窗口 | 端口开着就有人能连，没必要 7×24 挂着 |
| 开口令 | 公网/隧道场景一定带 `--token 长随机串` | 没有登录系统，口令是唯一门锁；**默认不带** |
| 别裸奔到公网 | 8799 不要无口令直接映射或暴露 | 等于把题库和进度交给任何扫到端口的人 |
| 区分云备份 | 远程访问 ≠ 云备份 | 远程访问只是换台设备操作**同一份本地数据**，电脑关机就打不开；WebDAV 云备份（坚果云等）才是把备份文件传到远端保存，两者互不替代，详见 `docs/REFERENCE-webdav-sync.md` |
| 数据仍是本地明文 | 口令只保护网页入口，不加密磁盘 | `state.json`、`history.json`、`banks\*.csv` 都是明文文件，电脑被拿走或被同步走，内容一样能读 |
| 公用 WiFi 慎用 | 咖啡馆、宿舍、学校网络里优先用 Tailscale | 同一网络里有人扫端口时，没口令的 8799 是敞开的 |
| 没有 HTTPS | 地址栏是 `http://` 时别输入其他账号密码 | 程序没有登录页，也不该被当成可信网站 |

## 7. FAQ

**1. 手机需要装 App 吗？**
局域网和 Cloudflare Tunnel 都不用，手机浏览器直接开；只有 Tailscale 需要在手机装它的 App。

**2. 手机上做的题，电脑 TUI 里看不到进度？**
两边读写同一份 `state.json`，但 TUI 只在启动时读一次状态。网页改完，重启 TUI 就能看到；反过来，TUI 里保存后刷新网页也能看到。**不要同时开着 TUI 和网页改同一份进度**，可能互相覆盖。

**3. 端口 8799 被占用怎么办？**
换一个，比如 `--port 8800`，然后所有地址里的 8799 一起改。想知道是谁占着，可以执行 `netstat -ano | findstr :8799`。

**4. 能不能只让手机看、不让它改？**
当前版本没有权限分级，能连上就能改。只能靠口令 + 只在需要时开服务来降低风险。

**5. 打不开时第一件事做什么？**
先在这台电脑上打开 `http://127.0.0.1:8799/`：本机能开 → 服务正常，问题在网络、防火墙或地址；本机也打不开 → 服务没起来，看命令行窗口的报错。

## 8. 适用范围与未验证项

- **已对照当前代码确认**：`--web`、`--port`、`--no-browser` 三个参数；默认只监听 `127.0.0.1`；控制台打印的地址格式；不写 `--port` 时端口随机；纯标准库、无登录、无 HTTPS；数据文件在项目目录内。
- **尚未实现、按「若你的版本支持」处理**：`--lan`（监听 `0.0.0.0` 并打印局域网地址）和 `--token`（可选口令，默认不带）。没有 `--lan` 时，只能用第 3.3 节的 `tailscale serve` 或 SSH 端口转发绕过。
- **属于通用做法、无法在代码里核实**：Windows 防火墙弹窗文案与菜单路径、各家路由器/光猫的菜单名称、Tailscale / cloudflared / DDNS 服务商的具体界面与命令细节（版本更新会变）。这些以各自官方文档和实际界面为准。
